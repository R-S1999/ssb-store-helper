# Retailer Relationship Improvement Engine

Serta Simmons Bedding proof of concept for independent mattress retailers. The app tells a store-performance story: who the lookalike peers are, how the store compares, where it is behind, why, what top stores and leading competitors do, and how large the surrounding market opportunity is.

## Screens

1. Peer Comparison
2. Store Performance Profile
3. Sales Associate Effectiveness
4. Customer Alignment
5. Display & Assortment
6. Pricing & Promotion
7. Inventory & Fulfillment
8. Store Identity
9. Store & Market Opportunity

Example values live in `src/lib/data.ts` so they can later be replaced by APIs without redesigning components. Market dollars are labelled **illustrative estimates**.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js App Router, Tailwind CSS, shadcn/ui. Deployed on Vercel.
